# AG2-React docs QA harness

Tests https://docs.copilotkit.ai/ag2 (React) page by page: doc code verbatim, HARNESS-marked glue only, one clip per page recorded in CI (`.github/workflows/daily.yml`). Open doc defects: [FINDINGS.md](FINDINGS.md). Page status, clips and Loom links: `assignment.json`. Start everything locally with `./start-all.sh`.
